# OYL
## What is this project all about?
Oleksandr Yarovyi Programming Language, or OYL for short, is
just my pet project to learn more about programming languages and computer architecture itself.
It's my attempt to make my own programming language and a
Java-based compiler for it.

## What does the project contain now?
For now, the project contains only a `Main` Java class that just echoes the parameters given to it.
